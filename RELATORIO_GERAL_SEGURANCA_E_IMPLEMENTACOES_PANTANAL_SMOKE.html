2. Auditoria e Blindagem do Supabase Storage (Bucket "products")

O Lovable Cloud emitiu o alerta preventivo: "Exposed personal & sensitive data — A rule lets anyone download files in products."

  • Verificação de Conteúdo: O bucket products foi auditado via API do Supabase e não contém nenhum dado pessoal, documento confidencial ou comprovante de cliente. O bucket é exclusivo para fotos do catálogo.
  • Origem do Alerta: A regra RLS anterior permitia SELECT público sem validar a extensão do arquivo, o que gerava o aviso heurístico do scanner de segurança.
  • Solução Aplicada (Migração 0005):
    1. Configuração explícita do bucket como público de mídia com limite de 5 MB por imagem e restrição de MIME Types para imagens.
    2. Política de leitura refinada para autorizar apenas extensões legítimas de catálogo: .png, .jpg, .jpeg, .webp, .gif, .svg, .avif, bloqueando qualquer outro tipo de arquivo.
    3. Políticas estritas de INSERT, UPDATE e DELETE vinculadas à função public.has_role(auth.uid(), 'admin').

4. Sistema de Autenticação e Recuperação de Senha (/admin)

Recurso Comportamento Implementado Garantia de Segurança
Login Administrativo Entrada oficial via supabase.auth.signInWithPassword() com verificação em duas camadas (RPC has_role e user_roles). Senhas protegidas no Supabase Auth; nenhuma chave ou senha mantida no frontend.
Esqueci Minha Senha Dispara e-mail com token seguro via supabase.auth.resetPasswordForEmail(). Token expira automaticamente e só pode ser utilizado uma única vez.
Redefinição de Senha Tela em /admin detecta o retorno (hash #type=recovery ou PKCE) e exibe formulário de Nova Senha. Validação de tamanho mínimo (6 caracteres) e confirmação obrigatória de senha.
Persistência no F5 Ao atualizar a página, a sessão JWT é revalidada contra o banco de dados. O administrador continua conectado; adulterações no localStorage são rejeitadas.
Bloqueio de Não-Admin Usuários sem a função admin são desconectados imediatamente. Exibe "Acesso negado: Este usuário não possui privilégios de administrador".
